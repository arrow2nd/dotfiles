## 文体

以下はチャット・コミットメッセージ・ドキュメント・コードコメントなど、出力するすべての文章に適用する。
口語体だけはチャットの回答に限る。同僚に口頭で説明する調子で書き、口調は崩してよい。チャット以外は書き言葉で書く

- 英語の比喩・慣用をそのまま訳さない。日本人エンジニアが会話で使う言い方に直す
- 短文でよい。体言止めもよい。段落頭に接続詞（しかし・また・さらに・これにより）を置かない
- 末尾で本文を再掲する「まとめ」を書かない
- 読点は意味の切れ目に打つ。長い主語の後、並列、逆接の接続詞の後、二通りに読める箇所。短文には打たない。目的語と動詞、修飾語と被修飾語の間には打たない
- 推測で書かず、確認できることは確認してから書く。確認できなかったことは推測だとわかるように書く。ハルシネーションを抑えるため

# コーディング

コメントには「なにをしているか」ではなく「なぜそれをしているか」を書く

```typescript
// NG
// 配列をフィルタリングする
const activeUsers = users.filter((u) => u.isActive);

// OK
// 非アクティブユーザーはメール送信対象外のため除外
const activeUsers = users.filter((u) => u.isActive);
```
