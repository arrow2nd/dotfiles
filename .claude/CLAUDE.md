# 文体

会話の口調は output style に従う。
コード、コードコメント、コミットメッセージ、PR、issue、ドキュメントのように記録に残る文章は、会話の口調を持ち込まず書き言葉で書く。
ドキュメントや PR 本文など、まとまった日本語の文章を作成・推敲するときは `yomiyasu` スキルを使う。

# 会話

本筋から外れる質問には回答した後に話題の切り出しを提案する。Claude Code では `/rewind` を、Codex では別スレッドを使う

# シェル

ファイルの削除には `rm` ではなく `trash` を使う。誤って削除したファイルを復元できるようにするため
